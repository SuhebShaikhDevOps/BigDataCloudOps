### 👨‍💻 About Me

Experienced **Multi-Cloud DevOps & Big Data Specialist** with **6+ years of industry experience** designing fault-tolerant cloud environments, automated release channels, and enterprise data platforms. 

- 🔭 **Architecting Solutions:** Production-grade deployments across **AWS, Azure, and GCP**.
- 🐘 **Big Data Operations:** Deep specialization in **Hortonworks (HDP)** and **Cloudera (CDP)**, managing large-scale HDFS, YARN, Hive, and Spark clusters.
- ⚡ **GitOps & Automation:** Building zero-downtime CI/CD workflows using **ArgoCD, Harness, Jenkins, and GitHub Actions**.
- 🔒 **Reliability & Security:** Hardening cloud networks, implementing IAM governance, and managing full-stack observability via **Prometheus & Grafana**.
